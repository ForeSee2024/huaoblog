## 你需要做的事

重新打开上面的后台链接即可使用新版；管理员 GitHub 账号为 `ForeSee2024`。只需按自己的情况继续调整简介、文章和已选图标。迁移保留了 1 篇真实文章、1 张原图片和先前未发布的站点配置；待发布配置需要你检查后再保存并发布。

日常写作不再要求 GitHub 分支保护、PR 评审、合并或网站构建。GitHub 仍用于程序源码和管理员登录；新的登录只请求身份读取权限。已有 GitHub 应用的历史仓库授权不会因为代码升级自动撤销。

## 写文章与发布

1. 在“文章管理”新建或打开文章，填写标题、分类、摘要、日期和正文。
2. 从富文本或 Markdown 模式写作，按需上传并插入图片、选择封面。
3. “保存草稿”保留未公开内容，`⌘/Ctrl+S` 也可保存。
4. 预览确认后点击发布。成功提示后刷新前台即可，无需等待 GitHub 或 Cloudflare 构建。

日期不是定时发布。编辑已发表文章时，保存草稿保留原公开版本；点击发布才更新访客内容。若提示其他窗口已修改，先刷新并核对版本。

## 批量删除与恢复

在文章管理或媒体资源勾选需要处理的内容，点击批量删除并核对清单。后台自动分批，显示完成或失败数量；发生网络中断先刷新核对，不要连续重复提交。

成功删除的内容不再出现在前台，回收站可恢复。当前文章、草稿或配置仍引用的图片不能删除。恢复文章如果缺少图片，先在回收站恢复图片。历史记录和回收站不是异机备份，仍需保留导出的 TAR。

## 配置网站与选择图标

站点设置、首页与导航、外观主题、关于与友链、页脚均可在后台操作。点击“保存并发布”直接更新公开配置，新请求生效。

关于页待选库包含 16 种系统、116 种技能与应用。搜索 Flutter、NextJS、VS Code 等名称，直接点选图标；取消选中即可移除，箭头调整展示顺序。无需自己填写名称、图标或说明。前台只显示你选中的项目，全部取消后隐藏该栏目。

## 下载备份与以后搬家

1. 打开“恢复与备份”，下载完整 TAR，并保存在电脑或其他独立存储。
2. 可以用同页的校验功能检查归档；超过 32 MiB 使用命令行。
3. 以后迁到自有服务器时，从线上再导出最新包，按 [迁移指南](MIGRATION.md) 恢复到空 SQLite 数据目录。
4. 按 [服务器部署](SELF_HOSTING.md) 启动 Node 或 Docker，验证后再切换域名。图片和历史包含在归档内，不需要逐篇搬运。

Cloudflare 每天 UTC 03:00（北京时间 11:00）计划生成完整 R2 备份，保留最近 7 份成功归档。应定期另存异地副本。自有服务器需要另设自己的定时备份；完全离开 Cloudflare 时还需部署 Node 登录网关，文档已有步骤。

更新 Worker 域名路由、DNS、`SITE_URL`、OAuth 来源白名单和 GitHub 应用主页；验证后让旧域名跳转。文章和图片继续使用原数据库和存储桶。当前正式域名是 `huaoblog.cn`，详细资源及回退信息见 [部署配置](DEPLOYMENT.md)。
