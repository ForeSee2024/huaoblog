## 1. 恢复 GitHub 自动部署授权

用途：后台发布文章或修改网站配置后，让 Cloudflare 自动构建新版。

1. 用 `ForeSee2024` 登录 GitHub，打开 [已安装的 GitHub Apps](https://github.com/settings/installations)。
2. 找到 **Cloudflare Workers and Pages**，点击 **Configure**。
3. 如果使用 **Only select repositories**，保留原有选择，加入 **huaoblog**，点击 **Save**。如果已允许全部仓库，则保持现有设置。
4. 打开 [Cloudflare 账号](https://dash.cloudflare.com/fc3766c02d25569ab3a3eb4d0cd6ae79)，进入 **Workers & Pages**。如果页面要求重新连接 GitHub，使用 `ForeSee2024` 完成本人授权。

当前 Cloudflare API 报错为 `8000011`（Git installation 内部异常）。如果授权页面仍报这个错误，记录提示发给我；先保留现有 App 安装与项目，我会继续核验恢复方式，避免影响其它站点。

授权完成后，我负责将现有 `huaoblog` 项目接到 `ForeSee2024/huaoblog` 的 `main` 分支并触发构建。现有项目、环境变量和域名可以直接使用。

## 2. 配置网页后台的 GitHub 登录

这与第 1 项的 Cloudflare GitHub App 是两个独立配置。

### 在 GitHub 创建 OAuth App

打开 [创建 OAuth App](https://github.com/settings/applications/new)，填写：

| 字段 | 直接复制的内容 |
| --- | --- |
| Application name | `HuaOvO Blog Admin` |
| Homepage URL | `https://aoblog.eu.cc/admin/` |
| Application description | `Huao（胡敖）的博客管理后台`（可选） |
| Authorization callback URL | `https://huaoblog-oauth.huaoqaq.workers.dev/callback` |

点击 **Register application**，记下 **Client ID**，然后点击 **Generate a new client secret**。如果之前已创建此用途的 OAuth App，可以复用它并核对上述回调地址。

### 把密钥直接填写到 Cloudflare Worker

1. 在 Cloudflare 的 **Workers & Pages** 中打开 **huaoblog-oauth**。
2. 进入 **Settings → Variables and Secrets**。
3. 添加下面两项，类型均选择 **Secret**：

| 变量名 | 值来自哪里 |
| --- | --- |
| `GITHUB_CLIENT_ID` | 刚才 OAuth App 的 Client ID |
| `GITHUB_CLIENT_SECRET` | 刚生成的 Client secret |

4. 点击 **Deploy / 部署**，使密钥生效。

密钥直接从 GitHub 复制到 Cloudflare；不要放进仓库、Pages 环境变量或聊天消息。已有的 `ALLOWED_ORIGINS` 保持当前值。
