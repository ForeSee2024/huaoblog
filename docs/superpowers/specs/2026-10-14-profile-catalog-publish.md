# 关于页选择目录与直接发布

## 目标

关于页系统、技能和工具可在后台持续维护，常用项目直接勾选，仅已选项目出现在前台。删除确认后继续完成受保护的发布，而不是把“删除”停留在创建 PR。

## 设计

- 共用 `src/data/profile-catalog.js` 作为系统、工具、分组和本地图标的目录。包含桌面与移动系统、编程语言、网页开发、数据与 AI、云与工程、编辑器、研究与笔记、设计与安全工具。目录不写进个人展示配置。
- 关于页后台以内置的 16 个系统、116 个工具图标为主要操作区。搜索或展开分组后直接点选品牌图标，自动带入名称；Flutter、Next.js 等主流框架不需要手动填写。已选列表显示图标与名称，支持上移、下移、移除，名称及提示调整收进可选设置；目录以外的自定义项目作为次要入口。保持现有明暗主题、实时预览和键盘原生复选框。
- 保持 `about.operatingSystems` 与 `about.tools` 的数据格式，兼容当前选择与自定义项目。扩大有效目录及数量限制，继续拒绝不安全图标名称和非法地址。
- 图标使用现有 Skill Icons 与 Simple Icons，保存本地 SVG 和许可证，前台和后台复用同一图标映射。
- 删除使用“删除并发布”确认；真正撤回的草稿直接结束，待发布的删除继续等待检查并合并。保存配置也明确为“保存并发布”。仅自动重试尚未结束的检查，网络错误、失败检查、权限或版本冲突立即停止并保留待发布记录。
- 等待检查有时间上限、处理阶段和重试入口；合并后明确提示网站自动更新中，避免将仓库合并误报为前台已上线。

## 验收

目录包括常见技术，搜索支持中英文名称和别名；选中、取消、排序、自定义项及旧配置保存回读正确。前台只渲染已选项目，所有品牌资源存在。发布等待只重试 `checks_pending`，失败或版本改变时不继续合并。验证空文章前台、明暗与窄屏、真实 GitHub 检查和 Cloudflare 部署，保留用户新草稿、图片及其他未发布设置。
