## 在后台修改

标签先保留文章的 1—2 个核心主题，优先复用已有标签。当前 7 篇文章使用 Web 开发、图学习、计算机视觉、文献管理、CTF、数学建模，共 6 个标签。后续文章出现新的主要主题时再增加，标签列表会自动随内容更新。

1. 打开 [管理后台](https://aoblog.eu.cc/admin/) 并使用 GitHub 登录。
2. 在“文章管理”打开对应文章，修改正文与摘要，需要时上传自己的图片。
3. 保存草稿便于继续编辑；完成后提交发布。
4. 在“发布与连接”检查并发布，Cloudflare 自动构建成功后前台更新。

初稿没有使用图库图片冒充项目截图，也没有填写演示 DOI 和外部仓库地址。正文中提到的 TGN 与文献工具说明使用原论文、作者代码和官方文档链接。
