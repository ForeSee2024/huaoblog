头像、作者名称与联系链接在“站点信息”修改；“关于页面”维护封面、个人介绍、使用语言、补充正文、系统与技能。封面可以上传并从媒体库选择，留空时使用全站主题底色。系统、技能清空后隐藏，GitHub 统计可关闭。当前简介仍为大概内容，可继续调整。

系统和技能用图标选择器维护：内置 16 种系统、116 种常用技能与应用，直接搜索并点选 Flutter、Next.js 等图标，名称自动填写。已选列表可排序或移除；名称及提示编辑、自定义项目都是可选功能，日常使用无需自己补齐图标库。

GitHub 详情使用公开资料，每次部署尝试刷新；暂时无法访问时，保留同账号的已核实公开快照并显示原更新日期。Star 和主要语言按最近更新的最多 100 个公开原创仓库统计，语言比例按仓库数量计算，不作为投入时间或熟练度。更换 GitHub 链接后不会展示旧账号数据；不读取私有仓库。没有填入 WakaTime、Osu! 和访客计数，后续有自己的资料后可以通过正文补充。

## 在后台修改

标签保留文章的 1—2 个核心主题，优先复用已有标签。旧初稿删除后，前台标签统计也随文章更新；后续文章出现新的主要主题时再增加，无需预先堆积标签。

1. 打开 [管理后台](https://huaoblog.cn/admin/) 并使用 GitHub 登录。
2. 在“文章管理”打开对应文章，修改正文与摘要，需要时上传自己的图片。
3. 保存草稿便于继续编辑；完成后提交发布。
4. 在“发布与连接”检查并发布，Cloudflare 自动构建成功后前台更新。

文章删除记录保留在 GitHub 提交历史，可按需恢复。更早的原文、旧配置和素材核对笔记保存在本机 `.local/content-review/2026-10-14/`，该目录已忽略，不进入 GitHub 或网站构建。完整操作见 [使用与上线清单](./上线操作清单.md)。
