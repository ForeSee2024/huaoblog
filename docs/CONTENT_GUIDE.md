## 文章和图片

1. 打开 [后台](https://huaoblog.cn/admin/)，使用管理员 GitHub 账号登录。
2. 新建文章，填写标题、分类、摘要、日期和正文；封面可选。
3. 保存草稿用于继续编辑，`⌘/Ctrl+S` 同样可保存。修改已发表文章时，草稿不会覆盖访客正在阅读的版本。
4. 核对预览后点击发布，文章与引用的图片直接对前台可用，无需检查或合并 PR。

标签优先复用已有主题，每篇保留 1—2 个关键标签。日期用于展示和排序；未来日期的文章点击发布后同样立即公开。

富文本与 Markdown 支持图片、链接、公式、表格和代码。行内公式用 `$...$`，独立公式用 `$$`。编辑器会把 `latex` 代码块视作公式；展示 LaTeX 原始代码时使用 `text` 围栏。

图片单张最多 10 MiB，支持系统校验通过的常见图片格式。上传后默认仅管理员可读取；发布文章或站点配置时，引用的图片才公开。媒体库保护当前文章、草稿和站点配置引用的图片。已经公开的图片不会因为文章改成草稿而重新变成私有，但删除媒体后将不再提供访问。

## 批量删除、冲突和恢复

文章与媒体支持勾选、筛选和批量删除。后台自动按小批次提交并报告完成数量；删除成功后，新的前台请求不再返回对应内容。已打开的页面请刷新。网络中断时先刷新工作区核对实际结果，再处理未成功项。

删除进入回收站，原始记录和文件仍保留；可在“恢复与备份”找回。恢复文章若提示图片已删除，先恢复图片。历史版本可在文章或配置界面查看并恢复；恢复也是新的一次有版本检查的写入。多个窗口同时编辑发生冲突时先刷新，避免覆盖较新的内容。

## 备份

“恢复与备份”可下载完整 TAR，并校验归档。浏览器校验上限 32 MiB；更大归档使用命令行工具。恢复仅允许空内容库，不能直接覆盖正在使用的正式数据。

Cloudflare 定时备份与 Node 异机备份说明见 [部署配置](DEPLOYMENT.md) 和 [自有服务器](SELF_HOSTING.md)。迁移时务必从当前数据库导出最新包，不能继续使用首次 Git 迁移包代替后续文章备份。
